# ADR 0043：Web 工作目录边界与会话恢复

状态：已接受

取代 ADR 0042 中关于页面离开时关闭会话、空工具表和无文件访问的 Web Host 决策；其余本地监听、密钥边界与生命周期决定继续有效。

## 背景

Web UI 需要在开始会话前选择本机工作目录，并在刷新后恢复同一会话。仅把 shell 的 `cwd` 设为所选目录不能限制绝对路径或父目录访问；把工作目录只保存在浏览器存储中也不能证明恢复后的会话仍使用最初授权的目录。先读取历史再建立 SSE 订阅还会在两次请求之间丢失事件。

仅绑定 loopback 也不能代替请求来源校验。浏览器中的其他来源仍可能向已知本机端口发送请求，DNS rebinding 还可能绕过只依赖地址的假设。

## 决策

Web Host 在系统文件夹对话框中取得工作目录，规范化后把 session ID 与目录的绑定持久保存于 Host 管理的元数据中。浏览器只保存 session ID；`POST /sessions/:id/open` 从 Host 元数据恢复目录，不接受浏览器提交的新目录。

`GET /sessions/:id/events` 在注册订阅者后读取持久事件快照。快照读取期间的新事件先进入每个订阅者的缓冲区；发送快照后，只补发 sequence 大于快照末尾的持久事件以及临时流事件，从而消除“读取历史后才订阅”的窗口。

Web Host 只提供经过 realpath 与祖先检查的 `list_dir`、`read_file` 和 `write_file`。任意 shell 无法仅靠 `cwd` 限制在工作目录内，因此 Web Host 不注册 `run_shell`。未来若需要 shell，必须通过提供文件系统与进程隔离的 sandbox capability 接入。

HTTP server 校验请求 authority 必须是实际监听的 `127.0.0.1` 地址；请求携带 Origin 时必须与该本机来源完全一致。Host 仍只适用于本机单用户场景。

## 后果

刷新页面能够恢复持久消息，恢复期间完成的回复不会因 SSE 建连时序丢失。工作目录授权由 Host 持久状态决定，修改浏览器本地存储不能把旧会话重新绑定到其他目录。文件工具拒绝符号链接逃逸和父目录逃逸；Web Agent 不再能运行构建、测试或其他 shell 命令。

会话工作目录元数据与 JSONL 会话日志是两份需要共同保留的数据。缺失或损坏元数据时，Host 拒绝恢复会话，而不是让浏览器重新指定目录。

## 放弃的方案

- 仅设置 shell `cwd`：它不阻止 `..`、绝对路径、子进程或 shell 内建命令访问目录外。
- 解析并过滤 shell 命令：shell 语法、程序间接访问和平台差异使字符串过滤不能构成安全边界。
- 信任浏览器 `localStorage` 中的工作目录：浏览器状态可修改，也无法在 Host 重启后证明原授权关系。
- 先返回历史再连接普通 SSE：两次请求之间存在不可关闭的事件丢失窗口。
- 仅依赖 loopback 监听：不能处理跨来源请求与 DNS rebinding 风险。
